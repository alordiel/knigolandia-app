# Knigolandia app — functional spec

Free iOS / Android / iPad app showing book reviews from knigolandia.info.
Only two categories: `hudozhestvena-literatura` (fiction) and `nehudozhestvena-literatura` (non-fiction).

## Stack
- Expo SDK 58, expo-router (Drawer), TypeScript
- react-native-webview — review HTML
- @react-native-async-storage/async-storage — lists, settings, offline index
- expo-file-system — catalogue JSON, offline review HTML, offline covers
- @react-native-community/netinfo — online/offline state
- expo-image — covers (`cachePolicy="disk"`)
- zustand (persist → AsyncStorage) — lists and settings state
- @tanstack/react-query — review and related-books fetching
- expo-notifications + expo-dev-client — push (needs a dev build, not Expo Go)

## Data sources (WordPress)

All `app/v1` requests send `X-Knigolandia-Key` (from `EXPO_PUBLIC_KNIGOLANDIA_KEY` in `.env.local`, not committed) — see docs/WORDPRESS.md §8. Requests go through `src/lib/api.ts`.

### Catalogue — `catalog.json`
- Static file: `wp-content/uploads/app/catalog.json`, regenerated by WP on `save_post`, `deleted_post`, `edited_term` (debounced via one WP-Cron event).
- Version check: `GET /wp-json/app/v1/catalog-version` → `{ "version": number, "url": string }`.
- ~3000 books, ~450 KB raw / ~100 KB gzipped. Always full replace, no deltas.

```json
{
  "v": 1739712000,
  "authors":     { "12": "Никълъс Иймс" },
  "translators": { "4": "Елена Павлова" },
  "publishers":  { "7": "Студио Арт Лайн" },
  "genres":      { "3": "Фентъзи" },
  "books": [
    { "id": 123, "title": "Кървавата роза", "heading": "Кървавата роза копнее да излезе от бащината сянка",
      "author_id": [12], "translator_id": [4], "publisher_id": 7, "genre_id": [3], "category": "fiction",
      "rating": 4.5, "reading-time": 6, "img": "2026/10/karvavata-roza", "mtime": 1739000000,
      "book_series": "The Band", "series_number": 2, "pages": 592,
      "ozone_url": "https://www.ozone.bg/product/…" }
  ]
}
```
| key | meaning |
|---|---|
| id | post ID |
| title | book title |
| heading | review headline (post title) |
| author_id / translator_id | author / translator IDs (post meta) |
| publisher_id | publisher ID (custom term) |
| genre_id | genre IDs (custom term) |
| category | `fiction` \| `nonfiction` |
| rating | star rating 0–5, halves allowed |
| reading-time | reading time, minutes |
| img | cover base path (no size suffix / extension) |
| mtime | modified timestamp |
| book_series / series_number / pages / ozone_url | optional, omitted when unknown |

Full field sources and server-side contract: docs/WORDPRESS.md.

### Review content
`GET /wp-json/app/v1/reviews/{id}` → `{ id, html, modified, date, link }`.
Internal links: `GET /wp-json/app/v1/reviews?slug={slug}` → `{ id }` or 404.

### Related books (online only)
`GET /wp-json/app/v1/related/{id}` → `{ sameAuthor: number[], similar: number[] }` (book IDs, resolved against the catalogue).

### Covers
Two hard-cropped WP image sizes, WebP:
- `app-thumb` 200×300 → `{base}-200x300.webp` (phone lists)
- `app-large` 400×600 → `{base}-400x600.webp` (iPad, detail header, 3x phones)
Pick by `PixelRatio.get() * tileWidth`.

## Startup sequence
1. Load `catalog.json` from file into memory (render immediately).
2. If online, non-blocking:
   - fetch `catalog-version`; if changed, download, write to file, swap in memory.
   - auto-cache the latest 10 reviews (see Offline).
3. Remove list entries whose book no longer exists in the catalogue (or show as unavailable).

## Storage
AsyncStorage keys:
- `lists` → `{ bookmarks: number[], wishlist: number[], readLater: number[] }`
- `offline:index` → `OfflineEntry[]`
- `settings` → `{ theme: 'system'|'light'|'dark', push: boolean, fontSize: number }`
- `catalog:version` → number

Files (expo-file-system, documentDirectory):
- `catalog.json`
- `reviews/{id}.html` — raw HTML as received
- `covers/{id}.webp`

```ts
type OfflineEntry = { id: number; savedAt: string; modified: number; pinned: boolean };
```
Never store HTML or the catalogue in AsyncStorage (Android ~6 MB total / ~2 MB per value).

## Lists
- **Bookmarks**, **Wish list**: IDs only, metadata from catalogue.
- **Read later** = offline download. Adding downloads HTML + cover (`pinned: true`); removing deletes the files.

## Offline
- Auto-cache: latest 10 reviews on every online app open (`pinned: false`). Entries dropping out of the latest 10 are deleted unless pinned. Re-download if `modified` changed.
- When offline:
  - show a banner "Офлайн режим · изображенията са скрити"
  - lists/search work from the catalogue; covers from file or expo-image cache
  - opening a review that is not on disk shows an "unavailable offline" state
  - hide "От същия автор" and "Подобни книги"
- Offline rendering strips media at render time (file keeps raw HTML):
```ts
const stripMedia = (html: string) =>
  html
    .replace(/<(script|iframe|video|audio|svg|picture|figure)[\s\S]*?<\/\1>/gi, '')
    .replace(/<img[^>]*>/gi, '');
```
Keep `p`, `em`, `strong`, `blockquote`, headings.

## Review screen
- Native-styled header (cover, details, rating, actions) + review body in a WebView.
- Prefer one full-screen WebView with the header rendered as HTML inside it (avoids WebView-in-ScrollView height issues).
- Inject stylesheet: fonts, size from settings, theme colours, `img { max-width: 100% }`.
- Rewrite lazy-load images (`data-src` → `src`) when online.
- `onShouldStartLoadWithRequest`: open external links with expo-web-browser; internal review links navigate in-app.
- Actions: Bookmark, Wish list, Read later. Share via RN `Share`.
- Below the review (online only): horizontal scroll rows "От същия автор" and "Подобни книги".

## Navigation (Drawer)
Ревюта: Художествена · Нехудожествена · Търсене
Моята библиотека: Отметки · Списък с желания · За по-късно (with counts)
Разглеждане: Издателства · Жанрове
Footer: Настройки

## Home / lists
- Tabs: Художествена / Нехудожествена. Genre chips filter.
- Card: cover, headline, author, translator, star rating, genre, reading time, offline badge.
- Search: `toLocaleLowerCase('bg')` over title, headline, author, translator.
- Publisher / genre screens: alphabetical list from lookup tables → filtered book list.

## Settings
- Theme: Системна / Светла / Тъмна (native + WebView CSS).
- Push "Нови ревюта": toggle registers/unregisters the Expo push token on the server (local-only toggle cannot stop remote pushes).
- Text size.
- Storage: catalogue date, offline count + size, "Изчисти автоматичния кеш" (unpinned only).

## Push (server side)
- Token table; `POST /wp-json/app/v1/push/subscribe` and `/unsubscribe`.
- `publish_post` hook (two categories only) → Expo Push API, batches of 100.
- `app.json` needs `extra.eas.projectId` (`eas init`).

## iPad
- Same layout as phone, not a sidebar layout.
- Home: two columns of cards.
- Review: content column max-width 800, centred.

## Out of scope / won't work
- Cross-device sync (no accounts) — lists live on device only.
- Background pre-download — refresh on app open only.
- Embeds and JS shortcodes inside reviews offline.
